# DSH Tsnet 皮肤（dsh-tsnet-skin-pilot）

给 DeepSeek Harness Web GUI 换一套"低饱和、跟着背景取色"的外观：背景、材质、刻度轨，
全都从同一套配色令牌长出来 —— 换背景，主色跟着变。

**零几何改动路线**：不动 DSH 的布局、不裁剪、不遮挡，连弹出层也不碰；所有改动都建立在
DSH 自己的 CSS 变量与插件槽位上。

## 装

```bash
dsh plugin --profile web add github:Obwiler/dsh-tsnet-skin-pilot
```

装完**重启 DSH**（bundle 层在启动时读）。撤：

```bash
dsh plugin --profile web remove dsh-tsnet-skin-pilot
```

目录里的 `install.ps1` 是 Windows 下的手动安装/卸载脚本（`-Uninstall` 撤），不依赖 profile 登记时可用。

## 有什么

- **背景 7 档**（位置：设置 → 常规 → 皮肤）：
  - `网格 · 战术台` —— 细网格 + 斜向排线（控制台默认档）
  - `纯色 · 无结构` —— 对照档：没有结构，磨砂就看不出来
  - `暖光 · 地平线` —— 暖色光晕
  - `拉丝 · 金属` —— 斜向拉丝，细条纹透过磨砂
  - `实景 · 相册图` —— 用站内真实图片当背景
  - `自定义 · 渐变` —— 点位与各点颜色自己配（在本行里编辑）
  - `图片 · 本地` —— 用本机选的图片当背景，模糊/暗化可调
- **材质 4 档**：`高`（模糊 34px · 透明 38%）/ `中`（26px · 45%）/ `低`（18px · 60%）/ `关`（不模糊 · 96% 实心，与 DSH 默认最接近的对照档）。
- **刻度轨**：右缘一条细刻度，按**对话轮数等距**排布，点一下跳到那一轮；活动刻度跟随滚动位置。
  手机形态下刻度间距与命中区放大到触控尺寸（有效命中区 ≥44px）。
- **取色**：主色跟随背景的色温（不写死品牌色），也可自选。
- **无障碍**：`prefers-reduced-motion` 下关闭本皮肤的动效（DSH 自身的动效不动）。

## 三条如实说明（它不是全功能）

1. **刻度是等距的**：位置表示"第几轮"，**不表示内容长度** —— 所以刻度位置不等于内容位置。
2. **刻度只统计当前已加载的视图**：DSH 只加载对话尾部，设置行会写明「当前视图 N 轮（更早历史未加载）」。
   历史总轮数在浏览器侧拿不到，所以不做假的总量。
3. **跨入口偏好同步需要一台配套中控台**：本皮肤可把偏好写到工作区 `.local/skin-prefs.json`，让不同端口/域名
   进来时保持一致；但这依赖中控台的 `/dsh-ftree-*` 路由。**没有它的机器上，这段同步整段关闭，只在当前入口
   生效**，设置行会如实写出这一状态。

## 兼容与边界

- 只作用于 DSH Web 的客户端插件槽位；不改 DSH 自身文件，卸载即复原。
- 不含任何第三方图片、字体或素材（背景是 CSS 渐变与内联 SVG 噪声；照片档由使用者自己提供）。
- 许可证：MIT，见 `LICENSE`。
